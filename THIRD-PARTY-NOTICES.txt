THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.VideoPlayback.Dav1d is a thin managed wrapper around dav1d, the
VideoLAN AV1 decoder, together with the native dav1d libraries it P/Invokes
into. Two distinct things in this repository come from other people, and both
are covered below:

  1. THE VENDORED SOURCE. dav1d-native-tools/dav1d/ is an unmodified snapshot of
     the upstream dav1d source tree, committed to this repository so the native
     libraries can be rebuilt from it alone, years from now, with no dependency
     that may have disappeared. It is the only source the native libraries are
     ever built from.

  2. THE SHIPPED BINARIES. The package's runtimes/<rid>/native/ folders contain
     libdav1d.so / libdav1d.dylib / dav1d.dll compiled from exactly that source,
     for seven runtime identifiers.

Both are governed by the licences reproduced in full below. Every one of them -
BSD-2-Clause, ISC, the NetBSD 2-clause variant, and one public-domain header -
is permissive and compatible with this repository's own BSD-2-Clause licence.

HOW BSD-2-CLAUSE CLAUSE 2 IS SATISFIED
    Clause 2 requires a binary distribution to reproduce the copyright notice
    and the licence "in the documentation and/or other materials provided with
    the distribution". Every build script in dav1d-native-tools/ copies dav1d's
    own COPYING file into its output folder as LICENSE-Dav1d.txt, and the adoption step
    copies it into runtimes/<rid>/native/ beside the binary. So the licence text
    physically travels inside the NuGet package, next to every native library,
    on every platform - in addition to this file.

WHAT WAS OMITTED FROM THE VENDORED COPY
    Nothing, apart from the upstream .git directory. The snapshot is the
    complete upstream working tree - source, headers, tests, tools, examples,
    documentation, meson crossfiles, CI configuration and all - so it can be
    diffed against upstream and built without additions. The exact copy command
    is recorded in dav1d-native-tools/dav1d/UPSTREAM.txt.

WHAT WAS MODIFIED
    NOTHING. Not one vendored file has been edited, renamed, reformatted or
    deleted. One file was ADDED, and it is a new file rather than a change to an
    existing one: dav1d-native-tools/dav1d/UPSTREAM.txt, which records where the
    snapshot came from. dav1d-native-tools/patches/ exists for the day a build
    needs a source change - applied at build time to a scratch copy, never to
    the snapshot - and as of 2026-08-28 it is empty. If a patch is ever added,
    this section must say so, because a patched binary is no longer plain
    upstream dav1d.

WHAT IS NOT THIRD-PARTY, AND IS DELIBERATELY ABSENT FROM THIS FILE
    dav1d-native-tools/test-vectors/*.ivf - the six AV1 conformance streams the
    build gate decodes. They were generated in this repository on 2026-08-28
    with ffmpeg, from its synthetic lavfi pattern generators (testsrc2,
    mandelbrot). There is no camera footage, no sample clip, nothing downloaded
    and nothing anyone else holds a copyright in. They are original content of
    this repository, and listing them here would be a false statement about
    their origin. The exact commands that produce them are in
    dav1d-native-tools/test-vectors/generate-test-vectors.sh.

    Upstream's separate dav1d-test-data conformance repository is NOT used and
    NOT vendored.

NuGet package dependencies are not listed here; this file covers source code and
binaries incorporated INTO this repository.

WHAT WAS INCORPORATED
    The entire upstream source tree, unmodified. The native libraries this
    package ships are compiled from it with:
        --buildtype=release -Ddefault_library=shared -Dbitdepths=8,16
        -Denable_asm=true -Denable_tools=true -Denable_tests=false
        -Denable_examples=false -Dxxhash_muxer=disabled
    so the shipped binary contains dav1d's decoder including its hand-written
    SIMD for x86 (SSE/AVX2), AArch64 (NEON, dotprod, i8mm) and RISC-V (RVV 1.0).

WHAT IS BUILT BUT NOT SHIPPED
    The dav1d command-line tool is built (-Denable_tools=true) because the
    verification gate uses it to decode the conformance streams and compare
    hashes. It is not included in the NuGet package.

WHAT IS PRESENT IN THE SNAPSHOT BUT NOT COMPILED INTO ANY SHIPPED BINARY
    * src/loongarch/* - LoongArch assembly. No LoongArch runtime identifier is
      shipped, so none of it is built. It is kept because removing files would
      make the snapshot no longer diffable against upstream.
    * tests/* - not built (-Denable_tests=false).
    * examples/* - not built (-Denable_examples=false).
    * tools/output/xxhash.c - the optional xxh3 muxer, switched off
      (-Dxxhash_muxer=disabled). It needs an xxhash.h that upstream expects the
      builder to supply; no xxHash code is present in this repository.
    * tools/compat/getopt.c and include/compat/getopt.h - compiled into the
      command-line tool only, and only on platforms whose libc lacks getopt.
      They are never part of the shipped library. They are covered by entries
      3 and 4 below.

    None. See "WHAT WAS MODIFIED" above.

INVENTORY: HOW THIS FILE WAS COMPILED, AND HOW TO RE-CHECK IT
================================================================================
On 2026-08-28 the vendored snapshot was inventoried mechanically, not by
reading around in it. The snapshot holds 360 files (359 from upstream plus the
added UPSTREAM.txt); 323 of them carry a copyright notice.

STEP 1 - every distinct notice, with a count:

    cd dav1d-native-tools
    grep -rl "Copyright" dav1d | xargs grep -h "Copyright" | sort | uniq -c | sort -rn

  79 distinct notice lines. Between them they name 21 distinct copyright
  holders: the 18 listed in entry 1 under dav1d's BSD-2-Clause, plus the x264
  project (entry 2), Todd C. Miller and The NetBSD Foundation (entry 4).
  Loongson appears in two places - most of its files are BSD-2-Clause (entry 1)
  and one is ISC (entry 3) - and is counted once. The two most common notices by
  far are "VideoLAN and dav1d authors" (160 files) and "Two Orioles, LLC" (127).

STEP 2 - which copyright-bearing files do NOT carry dav1d's BSD-2-Clause wording:

    for f in $(grep -rl "Copyright" dav1d); do
        grep -q "Redistribution and use in source and binary forms" "$f" || echo "$f"
    done

  Exactly five files, and each was then read:
    dav1d/src/ext/x86/x86inc.asm        ISC              -> entry 2
    dav1d/src/loongarch/loongson_asm.S  ISC              -> entry 3
    dav1d/src/dav1d.rc.in               covered by entry 1: its only "copyright"
    dav1d/tools/dav1d.rc.in             is a Windows VERSIONINFO string naming
                                        VideoLAN, in a resource template
    dav1d/CONTRIBUTING.md               prose about copyright policy, not a notice

STEP 3 - files carrying an ISC grant, which finds one the step-2 filter cannot
(tools/compat/getopt.c has TWO licence blocks, and the second one does contain
the BSD wording, so step 2 passes it over):

    grep -rl "Permission to use, copy, modify" dav1d
      dav1d/src/loongarch/loongson_asm.S
      dav1d/tools/compat/getopt.c        ISC + NetBSD 2-clause -> entry 4
      dav1d/src/ext/x86/x86inc.asm

STEP 4 - the file with no copyright line at all but its own terms:

    grep -rli "placed in the Public Domain" dav1d
      dav1d/include/compat/getopt.h      public domain (mingw-w64) -> entry 5

STEP 5 - what is NOT there. Searches across the whole snapshot for MIT
("Permission is hereby granted, free of charge"), for "Apache License", and for
"GNU General Public"/"LGPL" all returned NOTHING. There is no MIT, Apache or
copyleft code in the vendored tree. There is also no xxHash source anywhere in
this repository - only dav1d's own optional xxh3 muxer, which would need an
xxhash.h supplied from outside and is switched off in every build here.

Re-run steps 1 to 5 after any change to what is vendored, and update this file
to match. An entry that is out of date is worse than no entry, because it looks
like a statement someone checked.
